# Marca / Brand

Fuentes editables (PhotoCraft `.pcraft`, con capas) y exportaciones PNG.
Editable sources (PhotoCraft `.pcraft`, layered) and PNG exports.

| Archivo | Qué es |
| --- | --- |
| `hive-am-logo.pcraft` / `.png` | Isotipo: hexágono de mosaico en tonos de amarillo + abeja. Fondo transparente. Es `web/public/logo.png` y de él salen los iconos de `web/app/`. |
| `hive-am-logo-completo.pcraft` / `.png` | Isotipo + logotipo `hive-am`. Es `web/public/logo-completo.png` (el del README). |
| `hive-am-mascota.pcraft` / `.png` | Mascota en pixel art (abeja). |

Tipografía del logotipo: Bricolage Grotesque (la misma de la app), peso variable ~650, `opsz` 24.
